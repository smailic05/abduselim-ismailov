# Сайт с админкой

Сервер для сайта Абдуселима Исмаилова. Тексты произведений хранятся в базе на сервере, а не в репозитории. Посетители видят только то, что разрешено в админке: начало текста, полный текст или ничего.

## Установка на VPS

Нужен сервер с Ubuntu или Debian, открытые порты 80 и 443 и, по желанию, домен, направленный на IP сервера.

```bash
curl -fsSL https://raw.githubusercontent.com/smailic05/abduselim-ismailov/main/server/install.sh | sudo bash
```

Скрипт поставит Docker, скачает код в `/opt/abduselim-ismailov`, спросит домен и пароль для админки и запустит сайт. HTTPS-сертификат Caddy получит сам. Если домена нет, сайт откроется на `<IP>.sslip.io`.

После установки откройте `/admin`, войдите и на главной странице админки нажмите «Восстановить из файла», чтобы загрузить готовую базу со всеми произведениями (`site.db`).

## Обновление

Тот же скрипт: он подтянет новый код и перезапустит сайт, данные и пароль останутся.

## Где что лежит

- `server/data/site.db` — все тексты, биография и настройки. В git не попадает.
- `server/data/uploads/` — фотографии.
- `server/.env` — домен, пароль админки, секрет для входа.

Резервную копию можно скачать в админке кнопкой «Скачать копию».

## Запуск для разработки

```bash
cd server
pip install -r requirements.txt   # плюс pandoc, а для старых .doc ещё LibreOffice
DATA_DIR=./data ADMIN_PASSWORD=test SECURE_COOKIE=0 uvicorn app.main:app --reload
```

Заполнить пустую базу произведениями из HTML-файлов: `python -m tools.seed <папка с html> <фото автора>`.
